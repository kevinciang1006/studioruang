I'm art-directing the website for **Studio Ruang**, a Singapore-based residential interior design studio. "Ruang" means *space* in Malay/Indonesian. The studio is small, founded 2016, residential-first with select commercial work. Positioning: warm, editorial, quietly premium. Audience: homeowners commissioning bespoke interiors. Tone: calm, confident, understated — never loud or corporate.

**Aesthetic:** warm editorial minimalism. Think high-end interior design studio meets print magazine. Generous whitespace, large photography, asymmetric editorial grids, restraint over decoration. It should feel considered and expensive without being flashy. Avoid anything that reads as a website-builder template or stocky corporate design.

**Type**
- Display / headings: Fraunces (variable serif), used large and confident.
- Body / UI: Inter.

**Color palette**
- Background bone `#F5F1EA`
- Surface / alt sections `#EFE9DE`
- Primary text ink `#1C1A17`
- Secondary text `#6B655C`
- Accent (links, small highlights, primary CTA) clay `#A8543A`
- Hairline borders `#D8D0C2`

**Details:** near-square corners (2–4px radius), thin 1px hairlines, understated buttons (clay primary, ink outline secondary), subtle and smooth motion feel (no bounce). Real interior photography.

**Design these artboards:**
1. Homepage, desktop (1440px wide) — full page: hero (full-height, one large interior image, editorial headline, one-line descriptor, "Book a consultation" CTA); featured projects (3, asymmetric layout); a short studio intro strip; the 5-step process shown compactly; one large quiet testimonial; a closing CTA band; footer.
2. Homepage, mobile (375px wide) — same sections, mobile layout, with the mobile nav pattern.
3. Project detail page, desktop — full-bleed hero + project name, a meta row (category, year, location, scope), 2–3 short paragraphs, and an image gallery grid.

**Give me two distinct directions** for the hero and overall homepage rhythm so I can compare — e.g. one more photography-led and immersive, one more type-led and structured. Keep both inside the palette and type above. After I pick one, we'll refine spacing, hero treatment, and the projects layout.
